# Magic Button

## About the Project
This is a simple interactive button project that changes its colour every time it is clicked.I created this project to practise basic web development concepts and understand how JavaScript adds interactivity to a webpage

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Simple and attractive button design
- Button colour changes on every click
- Interactive user experience

## What I Learned
- Basic HTML structure
- Styling buttons using CSS
- Using JavaScript click events
- Changing button colours dynamically

## Conclusion
This project was a fun way to explore JavaScript and understand how small interactions can make a webpage more engaging.
